# ProLIF Web: real-structure conformance audit, 2026-09-04

**Not yet fully faithful.** The strict full-corpus gate fails, and three small
strict regression fixtures preserve distinct failures. No detector behavior was
changed or tolerated away during this audit.

## Inputs and reference

The same 16 seeded-random local Plinder systems used by the PLIP audit, but using
their complete `receptor.pdb` and all ligand SDFs. No downloads. This is one
available system per distinct PDB entry, not uniform sampling over all Plinder
systems or a train-only sample. All 16 native case processes completed.

Native ProLIF 2.2.1 / Python RDKit 2025.03.6; Web RDKit 2025.03.4. Each native
residue is serialized once, preserving parent atom indices and native residue
identity; both engines evaluate the same serialized graph and coordinates.
Explicit hydrogens are added once by native RDKit, not independently in Web.

evidence of strong interaction coverage.

Additional checks outside that successful-comparison denominator:

- **46 Web-only errors:** named protein water residues. Native implicit-H-bond
  rules skip them under default settings; Web lacks equivalent residue context
  and attempts geometry construction, which throws for an oxygen without heavy
  neighbors. Seven systems contain such errors. Weaver may exclude these waters
  during its own selection; this audit tests the library API, not that selection.
- **590 shared unsupported checks:** the default MDAnalysis VdW radius table
  lacks Fe or Ru. Both engines reject these inputs. These are not port-specific
  failures. The CSD-radius configuration is tested separately and does not have
  those missing-radius errors here.
- **2 shared unsupported implicit-H-bond checks:** a ligand oxygen with no heavy
  neighbors and no recognized water residue identity.

Only 7/16 structures satisfy the conservative full-coverage gate (no differences,
no one-sided errors, and no shared unsupported checks). That gate deliberately
does not count unsupported inputs as full conformance.

## Confirmed reproducible discrepancies

1. **Neighbor-angle ordering (`7GMZ`, also `2ZT4` and `2WYI`).** The same H-bond
   and scalar geometry are found, but the two donor-neighbor angles are reversed.
   Example: `[126.058665, 126.705228]` versus `[126.705228, 126.058665]`. This is a
   metadata-ordering discrepancy, not a different detected H-bond.
2. **Plane construction (`2WYI`, TYR596.A).** Native reports 13.647919 degrees;
   Web reports 13.972251 degrees. It appears in both donor and acceptor directions
   and both H states. Neighbor/extended-neighbor ordering is a likely mechanism;
   the saved fixture should drive a focused implementation audit before a fix.
3. **Default water exclusion (`1WNU` fixture).** Native returns no events; Web
   throws `No nearby heavy atoms found`. The native roundtrip explicitly restores
   residue metadata so this is not an accidental HOH-to-UNK oracle conversion.

## Preparation caveat: important beyond the detector

There are **39 rule/pair differences between native pre-serialization residues
and native re-parsed molblocks**, even with a looser geometry tolerance of 0.01.
They include 35 additional events after serialization and six shared-event
geometry differences. Some checks contain multiple differences.

Splitting/serializing isolated residues can change perceived chemistry: for
example a backbone nitrogen's perceived hybridization changes from SP2 to SP3,
altering implicit-H-bond geometry. Coordinates rounded to molblock precision can
also move a contact across a threshold. These are recorded separately and are
**not** attributed to the JavaScript detector. Thus the shared-graph agreement
does not establish end-to-end equivalence to native full-protein preparation.

The raw PDB preparation also provides **no positive cases** for salt bridges,
cation-pi, halogen bonds or the MetalAcceptor direction in this sample. Existing
committed Python reference fixtures supply targeted coverage for every ported
rule, but future real-structure audits need appropriately charged inputs and
targeted examples of these interactions. No scientific quality claim is made
for the plain-PDB preparation used here.
